# File Handling in Python

This repository contains a simple implementation of file handling operations in Python, focusing on working with custom logic, processing structured data, and managing system logs.

## Features

* **Script Operations**: Core logic implemented inside `file_handling.py`.
* **Binary Data Processing**: Read and write binary files using `data.bin`.
* **Logging**: Tracks events, runs, or system diagnostics inside `system.log`.

## Repository Structure

* `file_handling.py` - The main Python execution script.
* `data.bin` - Binary storage file for data serialization.
* `system.log` - Autogenerated runtime or diagnostic logs.

## Getting Started

### Prerequisites
Make sure you have Python 3 installed on your machine:
```bash
python3 --version
```

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the directory:
   ```bash
   cd File_handling
   ```
3. Run the script:
   ```bash
   python3 file_handling.py
   ```
